# 恒星材质与日珥生成

用于制作或改进程序化恒星光球、日珥云雾及其运动。这里整理可迁移的生成配方与失败教训，不附带项目着色器、机器路径、构建记录或画质通过声明。属于实时视觉近似；暖金色和短周期是艺术表达，不能解释为观测波段、物理温度或磁流体模拟。

## 先把效果拆成可控制的层

| 视觉目标 | 表示与材料来源 | 成立条件 |
|---|---|---|
| 有尺度层次的暖金色光球 | 解析球／已有网格上的物体坐标程序纹理，宏观区域＋中尺度斑块＋细颗粒 | 整体明暗先成立，细节不铺成等亮网格；保持球缘与受认可构图 |
| 有结构的黑子 | 扰动距离场生成暗核、半影及外围亮区，分别调强度 | 黑子不是纯黑贴片，外缘不靠大 Bloom 掩盖 |
| 连续柔软的日珥 | 曲线上的重叠软核云团，丝间保留低亮密度；内部少量窄亮丝 | 无 Bloom 时仍连续；从正面、侧面、背面检查 |
| 生成、扩展、变薄、消散、再生 | 几何生长与密度包络分别控制，重置位于不可见阶段 | 停止自转仍可辨认；流动方向另行判断 |
| 多区域、多尺寸活动 | 稳定身份的局部模板，球面朝向、扭转、跨度、高度、能量与相位各自控制 | 默认构图及完整周期均检查，不由活动区名称推断屏幕分布 |
| 克制的日冕与辉光 | 球外薄壳解析近似＋最后的 HDR Bloom | 日冕、实体云雾和后期溢光可以分别关闭 |

可迁移的成功方法是层次组织、云雾与亮丝配合、稳定实例和可辨认生消，不是某组颜色、数量或周期。共同束形、根部能量和共享输运规则见 [渲染方法](rendering-methods.md)；恒星表面多尺度场可有意采用不同速度，日珥需要共同流动时则使用共享输运坐标。迁移到其他天体前重新选择材料、形态与运动目标。

## 光球：先组织辐射，再添加细颗粒

1. 取得球面位置／法线及射线命中深度，把采样点变换回天体局部坐标。相机旋转只改变观察关系；自转通过变换表达，纹理随天体移动。
2. 用低频噪声产生小幅坐标扰动，再归一化回球面。宏观场决定活跃区域，中尺度场决定斑块，两个错位的细粒场交替演化。给每层独立尺度和速度，避免所有结构同速滑动。
3. 将上述场映射成线性 HDR 自发光颜色。暖棕暗部、暖金中间层与淡金亮点形成层次；RGB 可以超过 1，最终显示色由曝光与色调映射决定。不要直接复制行星昼夜光照或海洋镜面反射。
4. 用颗粒场的低值形成暗隙；亮细丝、脊线和局部高亮由活动区域调制，避免整个球面等亮发光。颜色、颗粒密度和亮度分开调参。
5. 黑子用球面局部距离场加小尺度扰动构成暗核、较浅半影、外围亮区。它们是独立遮罩，不能用一个硬阈值替代全部层次。
6. 用视线与法线夹角控制边缘亮度渐变；额外的方向明暗、局部边缘加亮作为艺术调色说明。以可见效果评估，不能把任意渐变称为真实辐射输运。
7. 按投影足迹抑制不可分辨细节，检查远近视角和球缘。已获认可的主体用固定参数、无损图保护；迁移时保留其曝光和后处理作为对照。

这套光球配方可以仅输出 RGB 与命中深度：噪声看起来有起伏，并不表示计算了高度法线、几何位移或自遮挡。若另加高度扰动法线，仍须区分着色变化与真实轮廓变化。

保护范围同时说明“独立光球输出”与“最终合成后的球面观感”。新增云层透射和 Bloom 可能改变后一项，即使球面着色器不变；按用户请求定义允许的覆盖与辉光范围，并分别核对。

表面亮区与日珥脚点最好读取同一活动描述，或有显式映射。**使用同一坐标空间不等于共享活动数据**：沿“配置→资源绑定→着色器读取”核查。若保留旧光球而新日珥独立布局，应说明两者尚未逐区连接，并单独检查根部；不要凭旧注释宣称已统一，也不要未经范围确认重做已认可球面。

## 日珥：云团构成体感，窄丝表达方向

为每个活动区定义稳定 ID／种子、两个球面脚点、峰点、能量与生命周期相位。在局部切向／法向基底中构建平滑拱线；脚点偏移后重新投影到球面。窄丝可以轻微编织、呼吸，但形变包络在两端归零。

保留旧组指保留其原始模板、身份与锚点；用户要求增加生长或消散时，可以在这些约束上叠加生命周期变化。

宽云雾采用沿中心线重叠的相机朝向软核云团，窄亮丝采用有限宽度曲线带。云团走较平滑的中心线，不能完全跟随高频编织。直接把窄带加宽，投影切线急转时内缘可能反折，形成三角亮缝；默认视角无缝不足以排除侧视失败。

一个可用的生成顺序：

```text
每个弧段：
  中心 = 曲线(段中点)
  Δs = 两端点间的弧段长度近似
  w = 基础宽度 × 根部渐隐 × 低频起伏 × 生长/消散包络
  像素宽度 = 在中心深度处把一像素反投影成与 w 相同空间的长度
  σ = sqrt(w² + 像素宽度²)
  绘制以中心为基准、面向相机的软核四边形
每个片元：
  在天体局部空间读取低频密度及细节
  用软核和截断边缘权重形成连续云体
  比较云团片元射线深度与球体命中深度
  累计发光量 E 与光学厚度 tau
```

均匀采样的云团要带步长权重，形式可从 `Δs / (σ × 核积分)` 起步，并依据所用核、截断、维度及亚像素展宽校准。投影核展宽时补偿贡献，不能增加段数就无依据地增加亮度。不要把一维窄丝的宽度补偿原样套在二维云团上。此处是近似归一化，必须用不同段数的无 Bloom 图验证收敛。

材质用连续低频底密度连接亮丝，再用小幅多尺度噪声调制云团厚薄与颜色。强阈值、过高沿弧频率、随机稀疏亮点容易生成断珠。沿丝方向使用弧长坐标，跨丝方向保持较低频率；跨宽度频率过高会被投影过滤全部抹成平均值。

云体纹理在天体局部空间采样，固定种子保持身份；仅自转时不能因世界坐标噪声而额外变质。密度、光学厚度、发光颜色与 Bloom 独立控制。若云团呈重复圆球，先调整低频分布、相邻核重叠或局部拉伸，重新验证侧视与归一化；加后处理模糊不能解决材料组织问题。

## 遮挡、日冕与合成

- 球体与云团比较同单位的射线距离，丢弃球后片元。窄丝与云层各自验证根部和球缘。WGSL 的 `dpdx/dpdy` 等导数先在一致控制流中计算，再执行非一致丢弃。
- 弱丝若使用低分辨率目标，重建时参考球体命中与发射深度，拒绝跨球缘的错误邻域贡献。单纯双线性放大容易漏光或断根。
- 薄日冕可在限定球外壳中，按视线穿越长度与径向衰减估计光学厚度。仅为球外边缘气氛服务；目标需要球前介质或复杂厚度时须重新定义该近似。
- 在采用 `E = source × tau` 的混合模型中，累计后用 `T = exp(-tau)`，再合成 `L = background × T + (E/tau) × (1-T)`；tau 接近零时采用稳定极限。这里 background 可以是命中的光球。
- 累计 E/tau 是混合近似，不能恢复不同颜色云层的深度顺序、云间自遮挡或多次散射。球体遮挡通过并不证明这些关系已解决。需要它们时再评估排序、分层或有界体积积分。
- 先让线性 HDR 的云体、亮芯和暗隙成立，再加 Bloom／曝光／色调映射。分别保存有无 Bloom 的对照。

## 运动：区分流动与生命过程

自转、局部演化与相机时钟分离。固定身份的双相位噪声输运可限制累计位移；相位混合需要检查周期边界、重复半周期和对比度下降。

生命周期可用独立包络表达，以下归一化时间仅作起始示例：

```text
q = fract(演化时间 / 生命周期 + 组相位)
消散 = smoothstep(0.55, 0.93, q)
密度 = smoothstep(0.02, 0.20, q) × (1 - 消散)
生长 = smoothstep(0.02, 0.30, q)
```

几何从球面连接向拱线生长；衰退时云体适度扩展，同时密度降低、细丝减弱。形变两端保持归零，完全不可见后重置。扩展不应同时把总亮度无意增加。

一个艺术化桌面起点可以采用 48 秒生命周期、24 秒纹理输运与 12 秒呼吸。它们便于观察和复现，不是物理时间，也不是所有效果应使用的默认值。隔离待测层与时钟，分别判断其真实周期；自转、非循环表面场或非公度时间函数可能使整页没有严格公共周期，不能承诺整页按生命周期常量重复。

停止自转后分别观看：亮斑是否沿弧行进、包络是否生长、是否变薄消失、是否平滑再生。生命周期明显但输运方向不清楚时，只判前者通过。多组错相能避免同时熄灭，但仍要检查某些阶段是否只剩右上主组吸引注意。

## 多尺寸模板：缩小活动范围，不把脚点缩进球内

从已成立的局部模板扩展。旧组保留稳定 ID、种子与几何路径；新增组控制球面中心方向、切向扭转、大小、能量与相位。不同大小不只缩小宽度，还应对应缩小脚点跨度、峰高及形变幅度。

对于单位半径坐标中的曲线点 `p`、单位活动中心方向 `c` 和缩放系数 `k`，可采用：

```text
r = length(p)
d = normalize(p)
d' = normalize(mix(c, d, k))
r' = 1 + (r - 1) × k
p' = d' × r'
```

该近似同时收缩球面范围和离表面高度；原本 r=1 的脚点仍在球面。适用于同一局部半球内的收缩模板，须避免反向插值归一化退化。对完整局部曲线统一应用一次，包括编织、生长、呼吸和消散，再施加天体姿态。直接使用世界坐标 `p×k` 会把脚点拉入球内。

组数增加后，用实例数据描述活动区与丝 ID，避免依赖固定三个 uniform 分支或因数量变化重排种子。低档保留高档中的嵌套子集，防止切档跳到另一组丝。弧长表与活动数据在几何配置变化时重建。

保留旧组参数不等于已验证新组合：新增组可能遮住原组、增加过绘，或因视角落在球后。小组可降低弱丝数量，但仍应保持主形态可读。用户指定组数或分布时，将其作为验收约束，优先调整组内可降级细节；未指定部分再按工程预算选择，无法兼顾时报告实际限制。新增模板的视觉、动态和性能均需要新证据。

## 实例调度：稳定身份不等于固定满场

区分候选实例池、正在活动的实例、成熟实例、弱消散尾迹与屏幕可见实例。按项目目标定义各自计数和重叠规则，不能从候选数量推导可见数量，也不把特定数量变成通用标准。

- 用固定种子与事件时间决定出生、持续、衰退和下一事件，避免每帧重抽造成跳变。实例完全不可见后才更换其位置或种子；保护实例按约定保留身份。
- 调度控制哪些实例在何时出现，局部模板控制怎样生长、变薄和消散。尾迹与下一出生可以错开，避免所有组同时熄灭或长期只剩主组，但不要求每组持续等亮。
- 局部生命周期可循环，整体事件日程不必同步循环；用户要求随机活动时检查多次事件与完整场景，不能用单个循环片段证明长期分布。
- 小模板薄雾弱或大模板遮住旧组时，先调整该尺寸的宽度、密度、能量及布局关系，再看归一化与预算；不要用全局提亮补救所有组。

## 计算边界与交付

把受认可光球、主丝与云层单独保护，将弱丝段数、噪声层数、分辨率和可选细节作为降级对象。全呈现分辨率的主层配 64 段、5 层噪声可作为某一桌面原型起点，不能当作设备保证。先测覆盖、材质采样、合成、后处理及队列成本，再决定减少哪一项。

缓存噪声体、活动实例与弧长表；光球缓存的键要覆盖相机、尺寸、自转／演化时钟、材质参数。停止自转不自动意味着光球材质静止。限制未完成提交，显式区分主动限帧等待与外部调度延迟；恒定负载下不应因自身等待反复降频，恢复也应确认瓶颈缓解。

按 [验证与对抗审核](verification.md) 交付：保护球面、单组无 Bloom、正侧背、多组完整页面、只局部演化录像、分层性能、档位闭环、回退与停止资源。明确三个限制：软核云团是投影近似；可见消散不代表可辨输运；旧数量／旧构建的结果不能担保新组合。具体项目的构建、截图、录像和用户评价保留在项目记录中。
