# 天体实时渲染的方法与契约

选择表示、迁移材质或修复空间／能量／时间／采样问题时阅读。以下是决策依据，不是固定引擎或参数要求。

## 从像素到表示

发光与消光近似可写为：

`L_pixel = T_end * L_surface/background + integral(T(s) * j(s) ds)`

`tau = integral(sigma_t(s) ds)`，`T = exp(-tau)`。

`j` 是发光系数，`sigma_t` 是消光系数；表达不自动包含多次散射、偏振或相对论输运。需要时另建模型。先定义表面反射光和自发光，再将它们作为边界辐射合成。[PBRT 透射率](https://www.pbr-book.org/4ed/Volume_Scattering/Transmittance)

| 目标关系 | 优先评估的表示 | 必须检查 |
|---|---|---|
| 清晰球体遮挡轮廓 | 已有解析球或球面网格，附加表面场／纹理 | 相机与深度一致，接缝／极区稳定 |
| 小尺度起伏，轮廓保持 | 高度导出细节法线、薄覆盖层 | 不称作几何位移或几何自遮挡 |
| 细长弧环、发射丝束 | 三维曲线带／有限截面几何，弧长材料 | 脚点、宽度、透视、前后遮挡与交叉 |
| 薄盘、薄发光／吸收层 | 局部解析光学厚度或薄层近似 | 斜视厚度、重叠次序、近似范围 |
| 厚介质、复杂吸收与穿越 | 包围区间内体积积分 | 步长收敛、空区跳过、联合透射与预算 |
| 明确要求强引力透镜 | 相应光线路径模型，可缓存相机相关解 | 科学／艺术范围、失效条件与成本 |

先复用已经满足目标的表示。不为“第一性原理”重写可用网格，也不只为厚重光效升级成全屏步进。

## 空间与方法迁移

- 物体局部场保持材质身份，旋转通过变换表达；相机改变观察关系，不使活动区漂移。
- 表面特征、活动区、脚点和近缘读取同一定位描述。共用关系与空间约束，不要求所有区域密度和根部相同。
- 球面脚点偏移后归一化并缩放到半径；非球面脚点投影到实际表面。明确局部切向、法向与弧长单位。
- 深度可以是射线距离、线性视空间深度或深度缓冲值；统一比较空间，不直接混合这些量。
- 纹理资产可用于行星表面。观察图、艺术目标和海报各有用途；二维图片铺球不自动产生三维介质或动态结构。

高度法线只改变着色。几何仍是解析球时，轮廓与几何遮挡仍由球决定；薄层吸收也不等于几何自阴影。[PBRT 凹凸映射](https://www.pbr-book.org/3ed-2018/Materials/Bump_Mapping)

| 方法来源 | 可以迁移 | 需要重新定义 |
|---|---|---|
| 地球 | 球面坐标、高度／法线、分层覆盖、深度约束 | 行星照明与恒星自发光；云、大气、海洋与等离子体的材料 |
| 黑洞 | 方向多尺度场、宏观调制细丝、有界输运、投影过滤、缓存、HDR | 坐标与流向；仅目标需要时采用吸积盘／引力公式 |
| 恒星活动区 | 表面与发射共享定位、锚点与能量分区 | 每类天体的极区、环、热点、喷流或表面分布 |

按本地代码核验源方法，不凭名称推断算法。迁移代码前检查版本、实际 API 和许可；使用同一运行库不表示同版本或同管线。

## 合成与能量

记录每个目标的输出契约，例如表面 `RGB + hitDistance`、介质 `radiance + T`、薄层 `E + tau`。Alpha 可能是覆盖率、透射率、光学厚度或深度，不能套同一混合。

常系数介质一段的增量为 `deltaL = T_in * (j / sigma_t) * (1 - exp(-sigma_t * ds))`；消光趋零时取 `T_in * j * ds`。统一距离单位与步长；增加步数不应增加同一路径发光总量。混合介质先合并同位置的发光与消光，再推进一条视线的透射率。

薄层可采用 `E = source * tau`，合成 `L = (E / tau) * (1 - exp(-tau))` 并保留背景透射。这个特定模型中 tau 为零时 E 也为零；不能替代所有独立发光模型。无序累计 E／tau 是混合近似，不自动恢复不同颜色源的前后吸收次序；目标接受误差时才使用，必要时与深度排序或联合积分参考比较。

曲线细分采用几何覆盖或正确长度权重，不重复叠加相邻段的光量。低分辨率上采样检查球缘与根部，必要时深度感知重建；仅双线性插值可能漏光或断根。

在线性 HDR 检查亮芯和暗隙，最后调曝光、Bloom 和色调映射。强 Bloom 不证明连接、层次或遮挡正确。

## 时间与采样

分离自转、局部演化和相机变量；固定种子与区域／细丝身份。按目标组合亮斑运输、密度演化与形变，不靠球体自转暗示局部运动。

以弧长运输，脚点形变归零。双相位淡化需检查随机场与权重对称性造成的半周期重复；零权重重置仅遮蔽相应跳变，还需验证完整周期与边界。

按投影足迹过滤，无法解析的细节回到平均贡献；细丝宽度通量按实际维度补偿，不盲目套面积比。防止跨宽度频率过高导致所有细节滤成均值。WGSL 隐式采样与导数受一致控制流要求约束，导数在非一致丢弃／返回前求值。[WGSL 导数规则](https://www.w3.org/TR/WGSL/#derivative-builtin-functions)

## 计算与生命周期

成本先按覆盖像素、候选几何、材质求值、积分步数、后处理和读回分解。用单层／仅主体／仅发射对照，避免给便宜部分降质。

缓存确定性噪声、静态图和可复用几何，列明失效依赖。曲线带通过光栅化限制覆盖；体积在材料区间积分，检查空区跳过及低透射终止误差。

按保护范围拆分主体与细节，再选择可调丝数、噪声层数、步数、分辨率或更新频率。项目确定参数和阈值，不照搬案例。

区分 GPU 时间、提交编码时间、完成等待、实际间隔。GPU 轻而间隔慢时先查 CPU／节拍，不能只按完成时间计算降帧上限。每个过载原因有有效动作或限制诊断；稳定恢复有迟滞，固定对照档不自动切换。

限制未完成帧，避免积压。隐藏暂停、恢复时钟与减少动态偏好需要实测；销毁、设备丢失和初始化复入防止旧回调访问新资源。回退状态明确，清空失效诊断。
