# 分项验证与对抗审核

规划、采集或审核证据时阅读。矩阵规模与风险相称：单个材质修复不机械复制大矩阵；公共切换、遮挡、运动和资源控制变化覆盖其相关场景。

## 比较条件

记录构建／提交、入口与完整参数、渲染器与实时／回退状态、相机、时间／模式、曝光／Bloom、种子、档位、CSS视口、设备DPR、实际呈现与离屏尺寸。图像大小与对应导出区域一致。

保护认可部分：哈希核对输入；固定参数的原生无损图核对输出。哈希不替代画面审核，有损截图差异不能单独证明材质改变。完整页面另检查卡片、导航、裁切与遮挡。

对齐最新用户选择与证据适用范围。撤销的参考不再作为目标；当前否定标为对应范围未通过，不能被旧“待确认”、历史认可或技术测试通过覆盖。保留历史记录，但不把它当作当前结论。静态参考只约束可见形态和材料，不能证明运动匹配。

## 局部到完整场景的退出判据

在现有审核记录中说明实际启用层、冻结时钟和待测关系，不强制新建文件。只隔离单簇但关闭云层时，结论限于该簇，薄雾保持未测。

| 检查顺序 | 可以进入下一步的可观察证据 | 不足时的最小动作 |
|---|---|---|
| 单结构几何 | 主形态、共同走向及连接符合目标；相关角度下脚点稳定，遮挡正确，无未解释的折叠／交叉 | 调父路径、方向基、锚点与宽度，不先加数量 |
| 单结构材料 | 固定曝光、无 Bloom 时层次与所需连续性成立；云、丝、暗隙可区分；根部无重复白团 | 分离包络、亮簇与细丝，检查局部能量及采样权重 |
| 局部运动 | 停止自转后目标运动可辨；方向、速度关系和重置符合约定 | 分别查输运坐标、几何与亮度包络，不用周期常量代替观察 |
| 多实例与页面 | 原实例保留，数量／分布符合约定，投影拥挤与 UI 遮挡可接受；保护范围、预算与生命周期通过相关回归 | 调允许变化的分布或次级细节，报告不能兼顾的约束 |

只采用与目标相关的判据：连续光柱不要求纤维暗隙，无局部运动目标不强加生消过程。局部技术通过不等于用户画质认可；不满足关键关系时停在局部原型，不用更多实例掩盖问题。

## 画质

- 单结构开始，检查正侧背及相关极端角度、锚点、连接、宽度、球缘、交叉和背面遮挡。
- Bloom关时结构成立，开时保留亮芯、暗隙和层次。
- 对比相关设备／视口与高低档，检查采样不足、网格、锯齿、闪烁、漏光与切档形变。
- 用户认可、参照差距与技术缺陷分别记录。单图认可不扩大为全部角度、档位和设备通过。

云团沿曲线叠加时，在同一时间与曝光下改变段数，检查包络和总亮度是否收敛；放大宽度后补查侧视折叠。新增活动区时保留旧实例身份，分别检查旧组、新增组和完整页面，旧组不变不证明新增组通过。核对表面亮区与脚点的实际数据绑定，不能只凭“共享活动区”的注释通过。

## 真实运动

隔离只自转、只局部演化、全停。固定时间图证明可复现状态；真实画布流／现场播放证明时间行为。

周期材料至少覆盖两个完整周期并留末尾余量，按解码末帧时间确认实际覆盖，不只看计划录制时长。观察半周期、完整周期和重置点，确认脚点、可感知运动、周期性变灰与跳变。

隔离待测层及其时钟后定义周期。若效果不是严格周期，或多个时钟没有公共周期，则按明确的生消阶段、重置事件和长时间漂移选择观察窗口，不伪造整页周期，也不机械等待不存在的最小公倍周期。

以下生消检查仅适用于目标启用生命周期的结构；其他局部运动按其输运或形变目标检查。

分别判断沿弧流动、几何生长、密度变薄、完全消失和再生。生命周期明显不自动证明输运方向可辨。多组错相检查整个周期的画面重心，留意上方与下方同时衰弱、主区长时间独占视线；不要求各组始终等亮。

全停同时核对冻结时钟与可见变化；有损录像允许编码误差，不要求逐像素相同。录制、完整视觉播放、解码分析分别描述，不互相冒充。

## 性能

同后端、尺寸、相机、运动、主体质量和后处理条件比较新旧或隔离层。记录预热、采样窗口、样本数、P50／P95、适配事件及硬件范围，沿用已定义门槛。

窗口内不截图、导出画布、编码录像或人为GPU读回。支持时用实际timestamp-query测pass，报告量化；不支持则GPU耗时未测／null。

| 指标 | 能支持 | 不能单独支持 |
|---|---|---|
| 帧间隔 | 提交节拍与稳定性 | pass GPU时间 |
| 异步完成等待 | 等队列完成延迟、背压 | 精确GPU执行时间 |
| GPU时间戳 | 所测设备／窗口的pass成本 | 所有硬件保证 |
| 录像帧率 | 编码节拍与覆盖 | 渲染GPU预算 |
| 离屏尺寸 | 内部目标大小 | 实际呈现DPR、截图完整性 |

策略输入覆盖持续过载、超过一秒慢帧、连续极慢帧、最低档、稳定恢复、固定档，以及GPU轻但间隔慢。策略检查和硬件负载实测分开记。

加入闭环输入：下一帧间隔包含控制器设置的主动等待。用恒定工作负载检查是否收敛，用持续调度瓶颈检查是否反复恢复又降级；再解除瓶颈验证实际恢复。只喂固定间隔的开环测试可能漏掉这两类反馈错误。缩放更多活动区后重新测总成本，旧数量的性能证据不能沿用。

## 生命周期与入口

按相关性验证拖动、键盘、复位、resize／DPR、手机边界、导航／历史、隐藏／恢复、减少动态偏好、无GPU、设备丢失、异步复入与销毁。

注入回退标明方法，手机宽度不等于实体手机。工具缺模拟或后台能力时保留未测状态，代码审查不冒充运行验收。

“看不到审核效果”先比URL、公共／实验条件、构建／资源版本、实时／海报、固定时间、档位、视口与UI遮挡。先查差异，再决定改入口，不能擅切公共版或关适配。

## 四类对抗问题

1. **方法迁移**：是否误带行星照明或吸积盘物理，把法线变化称作几何？是否从适合的局部原型开始？
2. **画质与性能**：是否降主体分辨率制造提速，或为细结构增加无必要全屏采样？有无成本对照？
3. **证据反驳**：静图、旧构建、离屏大小、编码帧率或零警告是否被当作动态／性能／画质通过？近似及缺测是否明确？
4. **入口与恢复**：公共页与审核图是否同版同参数？最低档过载是否有有效动作／诊断？旧回调、隐藏和设备丢失能否破坏恢复？

### 形态与材料反例

以真实目标和当前表示定位成因；下列是诊断分支，不是所有天体都必须出现的结构：

| 反例 | 优先隔离的原因与修正 | 不能冒充通过的证据 |
|---|---|---|
| 塑料磁环 | 平滑等宽、全程等亮或白芯压平层次；先重分配包络、亮簇、暗隙和窄丝 | 改名为等离子体、仅关闭镜面反射 |
| 蛇形射流 | 独立方向／空间摆动改写主束；先建单极父包络，限制相关偏移 | 增加丝数、更高频噪声 |
| 断珠云雾 | 核不重叠、阈值过硬或沿程频率过高；恢复连续底密度并检查步长权重 | Bloom 或后期模糊掩盖断点 |
| 极区白团 | 根部重复贡献；分别检查空间连接与 HDR 能量 | 锚点正确、降低全局曝光 |
| 连续光柱参考 | 保留连续柱形、外扩和衰减，仅补目标所需层次 | 强制拆成纤维束或增加分叉 |
| 生消明显但流动不明 | 隔离时钟，跟踪同一细节的方向及速度关系 | 周期参数正确、静图有变化 |

按“已验证／未通过／未测”分别报告画质、运动、性能、功能与设备范围。关键证据缺失不报全量通过；可交付受限实验或分析。
