# Celestial-body-formation-skill

从画面的实际成因出发构建天体：几何决定光来自哪里，材质决定光的强度与分布，遮挡决定哪些光到达相机，时间决定哪些关系变化，采样决定设备能稳定显示哪些细节。采用满足目标的最低成本表示。

## 先确定任务与证据

- **新建**：识别参考中的关键形态，建立可旋转、可隔离层的最小局部原型。
- **优化**：先核对用户正在看的入口和当前渲染器，测量或隔离成本；明确用户已认可、必须保留的部分。
- **审核**：核对源码、构建、参数与实际证据，分别给出发现、已验证范围和待验证项。审核不自动授权修改或切换公共页面。

先读工程入口、相关指令、依赖版本和 Git 状态。检查公共／实验路由、实时／海报状态、相机、曝光、时间、质量档、视口和实际呈现像素。记录与聊天提供线索，当前代码、绑定产物和用户选择决定本次工作。

利用现有信息明确视觉目标、可感知运动、设备和性能预算；仅询问会改变方案且无法从工程查明的关键问题。命令注明工作目录；不假设现成测试、GPU 接口或浏览器能力。

## 建立渲染契约

选择表示或设计材质时读 [渲染方法](references/rendering-methods.md)。为实现明确以下关系，不强制另建通用框架：

1. **空间**：物体、世界、相机与屏幕坐标；球面／网格、局部切向和深度单位。表面特征、根部与发射结构共享空间描述。
2. **能量**：反射或自发光、介质发光与消光、各目标 RGB／Alpha 语义；在线性空间合成，再曝光、Bloom 和色调映射。
3. **时间**：相机、自转和局部演化分别控制，固定种子维持身份；局部演化时脚点锚定。
4. **采样**：几何细分、积分步长、噪声频率、像素足迹及呈现尺寸；增加采样不应无依据地增加亮度。

## 选择表示并建立局部闭环

- 延续已适用的解析球或网格。法线细节用于表观起伏；目标需要轮廓变化或几何自遮挡时，再评估真实几何。
- 细长发射结构先评估有限宽度的三维曲线带；薄覆盖层先评估解析近似。需要复杂内部厚度、吸收和交错关系时，再使用有界体积积分。说明近似能表现与不能保证的关系。
- 借鉴地球的坐标与细节组织、黑洞的方向场与输运时，重新适配天体的能量来源和空间约束；不直接搬运无关照明、轨道或引力公式。
- 从单活动区、单发射簇或单表面区域开始。脚点偏移后重新投影到表面；以弧长组织流动，形变在锚点归零。没有这些结构的天体采用其对应最小局部原型。
- 先关闭 Bloom 检查连接、宽度、暗隙、正侧背面遮挡与交叉，局部通过后再增加数量与层次，最后调光效。

## 材质、运动与计算预算

用宏观分布组织微观细节，分离密度、颜色与发光强度，避免等亮线框或宽包络掩盖结构。按投影足迹过滤细节，检查不可分辨频率的平均贡献。WGSL 导数在一致控制流中求值。

局部演化在停止自转后仍应可辨认。循环使用固定身份和有界输运；检查完整周期、半周期与边界连续性，不能只读取标称周期参数。

按隔离成本决定优化对象：缓存静态内容，明确相机、尺寸、几何和材质变化的失效条件；只计算必要覆盖区域，限制未完成提交。将用户认可的主体与允许降级的细节分开，不静默降低主体画质。

区分 GPU 负载、CPU／调度延迟与提交完成等待。降级包含持续过载、极慢帧、稳定恢复迟滞和最低档仍超预算的报告；测试每一触发原因是否真正改变预算。继承项目或用户的目标帧率；示例档位、周期和数值不成为通用默认值。

## 验证、交付与清理

准备或审核证据时读 [验证与对抗审核](references/verification.md)。如需追溯某个获授权项目的专属来源，只在该项目内读取其自身记录；本公开 Skill 不包含项目专属案例、机器路径、构建记录或会话信息。

分别核验画质、真实运动、性能、生命周期和公共入口。每项绑定构建／提交、入口、参数、设备与证据；未测项明确写未测。用户视觉认可、参照差距、技术测试通过分别记录。

交付包含：表示及理由、保护范围、实际改动、完整参数复现入口、分项验证、风险／限制及下一步。检查实际页面与审核画面是否同版本、同参数；仅画布图不证明文字覆盖后的页面效果。

完成后对抗性复查：最低成本实现是否满足目标，优化是否损伤认可部分，证据是否支持结论，实际入口是否使用目标版本。关闭本次审计标签页，停止本次启动的网页服务、录像和 GPU 循环；保留证据。用户要求关闭全部网页服务时先识别服务，不把其他软件的本地监听端口当作项目网页服务。
