# PaperTrace external entry

[中文](README.md) | [English](README.en.md) | [Back to the root README](../README.en.md)

`30-papertrace/` is an external-project navigation directory. It does not store the canonical PaperTrace Skill source. `papertrace-skills.lnk` is only a convenience entry on the repository owner's machine and may not work on another machine or clone.

## Project role

PaperTrace owns project-specific Skills for paper-evidence extraction, bilingual reading, learning profiles, adaptive teaching, allegorical teaching, research briefings, and HTML presentation. The current source, scripts, and constraints are defined by [PaperTrace skills](https://github.com/jiaqi-Sun2020/PaperTrace/tree/main/skills).

## Usage boundaries

- Do not treat the `.lnk` file as portable source, a dependency, or an installation mechanism.
- Do not modify the shortcut's external target from this repository.
- Do not copy PaperTrace-owned Skills into this repository and create a second canonical source.
- Do not record the shortcut's machine-specific absolute path in public documentation.
- Before using a PaperTrace Skill, read its project README, Agent rules, and corresponding `SKILL.md`.

## Maintenance

When PaperTrace's public repository location or capability map changes, update only this navigation document. Implementation, testing, and publication remain in the PaperTrace repository.
