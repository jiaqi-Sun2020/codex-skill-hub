## P1 — PRL architecture and evidence

- [ ] Rewrite title around the result/mechanism.
- [ ] Rewrite abstract as problem → mechanism → evidence → implication.
- [ ] Rebuild first two introduction paragraphs for broad physicists.
- [ ] Define one central result and remove parallel storylines.
- [ ] Reduce to current PRL length budget.
- [ ] Move reproducibility and specialist details to End Matter/SM.
- [ ] Make held-out evidence primary and quantify uncertainty.
- [ ] Add/repair mechanism-discriminating controls.
- [ ] Narrow hardware claims or add resource analysis.

## P2 — Language and production

- [ ] Normalize terminology and hyphenation.
- [ ] Split overloaded sentences and remove equation restatement.
- [ ] Replace promotional words with quantitative statements.
- [ ] Check tense, articles, agreement, punctuation, and notation.
- [ ] Check REVTeX compatibility and remove unnecessary formatting overrides.
- [ ] Check figures for accessibility and caption economy.
- [ ] Add Data Availability Statement.
- [ ] Compile, inspect, and run final reference/label checks.

## Final gates

- [ ] No unresolved P0 issue.
- [ ] One defensible PRL claim.
- [ ] Broad-interest case is explicit.
- [ ] Evidence supports every major claim.
- [ ] Within current APS word-equivalent limit.
- [ ] Main paper is self-contained.
- [ ] End Matter/SM preserves reproducibility.
- [ ] Clean compilation and visual QA.
