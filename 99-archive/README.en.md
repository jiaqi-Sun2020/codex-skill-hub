# Historical archive

[中文](README.md) | [English](README.en.md) | [Back to the root README](../README.en.md)

`99-archive/` retains provenance or historical explanation for material that has left the active workflow. Archived content does not participate in Skill discovery, startup loading, current configuration resolution, or fact determination.

## Archive principles

- Archive means inactive; it does not mean the content remains compatible, correct, or safe.
- Current facts come from canonical source, configuration, tests, and approved project knowledge, not archived copies.
- Do not execute scripts, load Agent instructions, or synchronize Skills directly from the archive.
- Before restoration, recheck provenance, license, dependencies, schemas, paths, safety boundaries, and current tests.
- Restore only the smallest reviewed content by copy or migration; do not turn an entire historical directory directly into active source.
- Deleting or rewriting historically valuable archive material requires explicit project-owner approval.

## Current state

This directory currently contains no active Skill. The README defines archive semantics only and creates no new retention, deletion, or migration authority.
