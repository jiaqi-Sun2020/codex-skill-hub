# 历史归档区

[中文](README.md) | [English](README.en.md) | [返回根 README](../README.md)

`99-archive/` 保存已经退出当前工作流但仍需要保留来源或历史解释能力的材料。归档内容不参与 Skill 发现、启动加载、当前配置解析或事实判断。

## 归档原则

- 归档表示“不再活动”，不表示内容仍兼容、正确或安全。
- 当前事实以正式源码、配置、测试和获准项目知识为准，而不是归档副本。
- 不从归档目录直接运行脚本、加载 Agent 指令或同步 Skill。
- 恢复前必须重新检查来源、许可证、依赖、Schema、路径、安全边界和当前测试。
- 恢复应复制或迁移经过审核的最小内容，不把整个历史目录直接变成活动源码。
- 删除或改写具有历史价值的归档材料需要项目所有者明确批准。

## 当前状态

本目录目前不包含活动 Skill。README 仅定义归档语义，不创建新的保留、删除或迁移授权。
